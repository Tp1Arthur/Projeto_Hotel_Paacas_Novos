## 🏔️ O Projeto

<table>
<tr>
<td width="70%" valign="top">

O **Pacaás Novos** é um sistema web desenvolvido para apoiar a **gestão administrativa e operacional de um hotel**, reunindo em uma única plataforma os principais processos da operação hoteleira — da recepção ao financeiro, do estoque aos eventos.

A solução foi concebida sob a perspectiva do **administrador e do gerente do hotel**, permitindo centralizar informações e acompanhar, em tempo real, cada área do estabelecimento.

O projeto também é uma aplicação prática dos conceitos de **Engenharia de Software** e **Engenharia de Requisitos**, cobrindo desde o levantamento do domínio de informação até a especificação formal de requisitos funcionais e não funcionais, com desenvolvimento incremental por Sprints.

</td>
<td width="30%" valign="top">
